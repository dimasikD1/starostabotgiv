# Starosta Bot — расписание и опросы

Telegram-бот для старосты.

## Расписание
- /group — выбрать учебную группу;
- /schedule — сегодня;
- /tomorrow — завтра;
- /week — неделя.

## Опросы и группы

1. Добавьте бота в нужную Telegram-группу.
2. Дайте боту право отправлять сообщения.
3. Администратор группы выполняет `/attach`.
4. Откройте личные сообщения с ботом.
5. Создайте опрос:
   `/poll Кто будет на собрании? | Буду | Не буду | Пока не знаю`
6. Выберите группу или «Во все группы».

Удалить группу из рассылки можно командой `/detach` внутри неё (только администратор).

Список групп в личке: `/groups`.

Данные групп и пользователей хранятся в `/data/users.json`.

## Источник расписания

## Amvera
Переменная:
`TELEGRAM_BOT_TOKEN`

Дополнительно:
`SCHEDULE_SITE_URL`, `SCHEDULE_API_URL`, `SCHEDULE_DAYS`, `SCHEDULE_TIMEOUT`.

Не добавляйте реальный токен Telegram в Git.
