# Староста Бот

**Староста Бот** — Telegram-бот с Mini App для организации учебной жизни студентов, старост и администрации учебных заведений.

Проект объединяет расписание, работу с учебными группами, посещаемость, домашние задания и объявления в одном интерфейсе.

- **Telegram-бот:** [@starostagivbot](https://t.me/starostagivbot)
- **Канал обновлений:** [@starostabotgiv](https://t.me/starostabotgiv)

## История проекта

«Староста Бот» — самостоятельный образовательный стартап, который начал развивать обычный выпускник среднего профессионального образования Краснодарского кооперативного института (ККИ РУК), направления ИСП.

Идея проекта выросла из реальных задач студенческой жизни: упростить работу старост, сделать учебную информацию доступнее и собрать расписание, посещаемость, домашние задания и объявления в одном месте.

Проект развивается постепенно — от решения задач своей учебной среды к идее единой платформы, которой смогут пользоваться разные колледжи и университеты. Это независимая инициатива, создаваемая небольшими шагами, с опорой на обратную связь студентов и старост.

## Возможности

### Для студентов
- Просмотр расписания на сегодня, завтра и неделю.
- Просмотр информации о своей учебной группе.
- Доступ к домашним заданиям и объявлениям.
- Работа с Mini App внутри Telegram.

### Для старост и заместителей
- Управление студентами своей учебной группы.
- Работа с посещаемостью по отдельным занятиям.
- Опросы и взаимодействие с участниками группы.
- Публикация и просмотр учебной информации.

### Для администраторов и владельцев
- Управление учебными группами и пользователями.
- Назначение старост и заместителей.
- Регистрация учебных заведений.
- Назначение администраторов учебных заведений.
- Разделение данных и доступа по учебным заведениям.

## Mini App

Mini App адаптирован для открытия из Telegram и включает основные разделы студенческого кабинета и инструменты управления. Интерфейс рассчитан в том числе на мобильный Telegram WebView.

- Мгновенный показ последних сохранённых данных при открытии и при временной недоступности сервера.
- Подсказка «Сейчас идёт пара» с обратным отсчётом до конца занятия.
- Расписание на сегодня, завтра и неделю, посещаемость по парам, домашние задания с фото и видео.
- Объявления и отчёты в HTML.
- Кнопка обновления данных и автоматическое обновление при возврате в приложение.

## Поддерживаемые учебные заведения

Проект развивается в сторону единой платформы для нескольких колледжей и университетов: каждое учебное заведение получает собственные группы и административные права.

Текущая структура данных предусматривает привязку групп к учебному заведению. Развитие иерархии факультетов, направлений и курсов продолжается.

## Команды

Ниже перечислены основные команды. Доступность отдельных административных команд зависит от роли пользователя.

| Команда | Назначение |
| --- | --- |
| `/group` | Выбор учебной группы |
| `/schedule` | Расписание на сегодня |
| `/tomorrow` | Расписание на завтра |
| `/week` | Расписание на неделю |
| `/groups` | Список подключённых групп |
| `/attach` | Подключение Telegram-группы |
| `/detach` | Отключение Telegram-группы |
| `/poll` | Создание опроса |

## Технологии и структура проекта

- Node.js 20
- Telegram Bot API
- Mini App на HTML, CSS и JavaScript
- Хостинг и запуск приложения — Amvera

Основные файлы:

- `bot-amvera/index.mjs` — сервер, Telegram-бот и основная логика.
- `bot-amvera/webapp/index.html` — интерфейс Mini App.
- `amvera.yaml` — конфигурация развёртывания.
- `package.json` — зависимости и команды проекта.

## Развёртывание

Проект рассчитан на запуск в Amvera из GitHub-репозитория.

1. Подключите репозиторий к приложению Amvera.
2. Укажите необходимые переменные окружения.
3. Запустите сборку и проверьте логи приложения.
4. Для автоматического запуска обновлений после отправки изменений в GitHub настройте GitHub Webhook в настройках репозитория и приложения Amvera.

### Переменные окружения

Обязательная переменная:

- `TELEGRAM_BOT_TOKEN` — токен Telegram-бота.

Дополнительные параметры:

- `WEBAPP_URL` — публичный HTTPS-адрес Mini App для кнопки «Открыть кабинет».
- `TIME_ZONE` — часовой пояс расписания и посещаемости, по умолчанию `Europe/Moscow`.
- `DATA_DIR` — каталог данных, по умолчанию `/data`.
- `OWNER_TELEGRAM_ID` — числовой Telegram ID владельца.
- `DB_BACKUP_INTERVAL_MS` — как часто обновлять резервную копию базы, по умолчанию раз в 60 секунд.

Параметры расписания:

- `SCHEDULE_SITE_URL`
- `SCHEDULE_API_URL`
- `SCHEDULE_DAYS`
- `SCHEDULE_TIMEOUT`
- `SCHEDULE_BRANCH`, `SCHEDULE_KIT`
- `SCHEDULE_BRANCH_ID`, `SCHEDULE_GROUP_ID`

Фактический набор переменных зависит от конфигурации приложения. Не публикуйте токены, пароли, webhook secrets и другие секреты в репозитории.

### Проверка работоспособности

Сервер отдаёт `GET /healthz` с версией и временем работы. Ответ `200` и `{"ok":true}` означает, что процесс запущен. Для проверки сборки и тестов:

```bash
npm run check
npm test
```

## Данные

Работа с данными пользователей и учебных групп зависит от настроенного хранилища приложения. В текущей конфигурации используется каталог данных `/data`. Убедитесь, что для него настроено постоянное хранение на хостинге.

## Важные замечания

- Расписание зависит от доступности источника расписания учебного заведения.
- При сбоях внешнего источника приложение должно по возможности сохранять и показывать ранее загруженные данные.
- Распознавание списков студентов по фотографии (OCR) сейчас отключено.
- В проекте нет пользовательского интерфейса подписки.

## Статус миграции на TypeScript

Работа ведётся в отдельной ветке `typescript-migration`. Production-ветка `main` и приложение Amvera не переключаются автоматически.

**Последний выполненный этап:** перенос сохранения операций со списком студентов в TypeScript workflow. Добавление по Telegram ID, добавление вручную и удаление из списка сохраняют базу только после успешного изменения; дубликаты, лимит списка и неверный номер не вызывают лишнее сохранение.

**Оценка оставшейся работы:** около 5 крупных этапов:
1. Завершить перенос оставшихся административных команд и управления учебными заведениями, группами и студентами.
2. Перенести остальные Telegram-команды, inline-кнопки и callback handlers.
3. Завершить перенос регистрации, middleware и проверок доступа, оставшихся в JavaScript.
4. Перенести фоновые задачи, уведомления и публикацию расписания.
5. Завершить TypeScript entrypoint, полную сборку и проверку совместимости с Amvera.

Это ориентировочная оценка по функциональным блокам, а не процент готовности. Список обновляется после завершённых этапов. Миграция считается завершённой только после прохождения CI и проверки запуска; production переключается только по отдельному подтверждению.

## Разработка

Во время миграции изменения вносятся в отдельную ветку `typescript-migration`. Не переключайте Amvera и не объединяйте изменения с `main` до отдельного подтверждения. После согласованного развёртывания проверьте runtime-логи Amvera, бота и Mini App в Telegram.
