# Starosta Bot — расписание

Чистая версия Telegram-бота для старосты. Тестовые группы, демонстрационные пользователи и фиктивное расписание удалены.

## Команды
- /start
- /help
- /group
- /schedule
- /tomorrow
- /week

Выбранная группа хранится в /data/users.json.

Источник расписания:
https://new-schedule.ruc.su/schedule

## Amvera
Задайте переменную TELEGRAM_BOT_TOKEN. Node.js 20.

Дополнительно:
- SCHEDULE_SITE_URL — источник расписания;
- SCHEDULE_API_URL — необязательный JSON API;
- SCHEDULE_DAYS — количество дней, по умолчанию 7;
- SCHEDULE_TIMEOUT — таймаут запроса, по умолчанию 15000 мс.

Если сайт загружает расписание только через JavaScript или блокирует автоматические запросы, потребуется отдельный API-адаптер. Бот не подставляет вымышленные данные.
