# Пустой Telegram-бот

Рабочий бот лежит в `bot-amvera/`. Он запускается long polling и отвечает, что бот пустой. Журнала, расписания, базы и команд нет.

Корневой `amvera.yml` запускает `bot-amvera/index.mjs`. Веб-интерфейс в корне в конфигурацию Amvera не входит.

## Запуск на Amvera

1. Подключите этот репозиторий.
2. В переменных проекта задайте `TELEGRAM_BOT_TOKEN` от `@BotFather`. Токен в репозиторий не кладите.
3. Соберите проект. Нужен Node.js 20.

Копия того же пустого бота без health-check — в `starost-bot/`.
