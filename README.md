# Староста 24 — развертывание на Amvera

В этом репозитории есть веб-интерфейс в корне и Telegram-бот в `bot-amvera/`. Корневой `amvera.yml` настроен запускать именно бота; веб-интерфейс в конфигурацию Amvera не входит и остаётся в исходниках.

## Развертывание всего репозитория

1. Создайте проект Amvera и подключите этот GitHub-репозиторий, ветку `main` (после слияния настроек) или ветку с конфигурацией.
2. В переменных проекта задайте `TELEGRAM_BOT_TOKEN` — токен от `@BotFather`. Не добавляйте токен в GitHub или `.env.example`.
3. Используйте точку постоянного хранилища `/data`. Она уже указана в корневом `amvera.yml`; база `db.json` сохраняется между пересборками.
4. Запустите сборку и развертывание. Конфигурация использует Node.js 20 и запускает `bot-amvera/index.mjs` в режиме long polling.

`DATA_DIR=/data` можно задать явно, но бот сам выбирает `/data`, если том доступен для записи. Для режима приложения конфигурация указывает порт 80 для health-check сервера.

## Развертывание только папки бота

Если загружаете в Amvera не весь репозиторий, а только содержимое `bot-amvera/`, используйте вложенный `bot-amvera/amvera.yml` и команду `npm start`. В этом случае корневая конфигурация этого репозитория не нужна.
