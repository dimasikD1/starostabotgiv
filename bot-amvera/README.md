# 🎓 Telegram-бот «Староста 24» — Версия для Amvera Cloud & GitHub

Умный помощник для студенческой группы университета. Позволяет старостам и студентам вести журнал посещаемости, смотреть расписание занятий, отслеживать дедлайны по домашним заданиям, голосовать в опросах и читать важные объявления кафедры.

---

## ⚡ Особенности конфигурации для Amvera Cloud

- ✅ **Файл `amvera.yml` уже настроен**: указан Node.js 20, команда запуска `npm start` и постоянное хранилище `/data`.
- 💾 **Защита данных (Персистентность)**: база данных `db.json` сохраняется в смонтированный том `/data`. При повторных деплоях из GitHub ваши данные об attendance, голосах и привязках **не удаляются**!
- 🛡️ **Безопасность**: токен бота передается через переменные окружения Amvera, а не хранится в открытом коде на GitHub.
- 🩺 **Двойной режим (Worker / Web)**: может работать и как фоновый процесс (long polling), и как веб-приложение со встроенным health-check сервером на порту `$PORT`.

## 🚀 Пошаговая инструкция: Заливка на GitHub

### Шаг 1. Создайте новый репозиторий на GitHub
1. Перейдите на [github.com/new](https://github.com/new).
2. Введите название репозитория (например, `starost-bot` или `starosta-24`).
3. Выберите тип **Public** или **Private** (по вашему желанию).
4. **Не** ставьте галочки «Add a README file» или «.gitignore» (они уже есть в проекте).
5. Нажмите **Create repository**.
6. Скопируйте ссылку на репозиторий (вид `https://github.com/ВАШ_ЛОГИН/starost-bot.git`).

### Шаг 2. Инициализируйте Git и отправьте код
Откройте терминал в папке с проектом и выполните команды:

```bash
# 1. Инициализация локального git-репозитория
git init

# 2. Добавление всех файлов (секреты из .env автоматически игнорируются)
git add .

# 3. Первый коммит
git commit -m "feat: initial commit for Amvera Cloud"

# 4. Установка главной ветки main
git branch -M main

# 5. Привязка вашего GitHub репозитория (замените на свою ссылку!)
git remote add origin https://github.com/ВАШ_ЛОГИН/starost-bot.git

# 6. Отправка кода в GitHub
git push -u origin main
```

## ☁️ Развертывание в Amvera Cloud

### Шаг 1. Регистрация и создание проекта в Amvera
1. Войдите в личный кабинет на [amvera.ru](https://amvera.ru).
2. Нажмите кнопку **«Создать проект»**.
3. Задайте имя проекта (например, `starost-bot`).
4. Выберите тип: **«Фоновый процесс»** (рекомендуется для Telegram-ботов) или **«Приложение»**.

### Шаг 2. Подключение репозитория GitHub
1. В способах доставки кода выберите **GitHub**.
2. Авторизуйте Amvera в вашем аккаунте GitHub (если делаете это впервые).
3. Выберите репозиторий `starost-bot` и ветку `main`.

### Шаг 3. Настройка переменных окружения (Секретов)
1. В настройках проекта Amvera перейдите во вкладку **«Переменные»** (Variables).
2. Добавьте переменную:
   - **Имя:** `TELEGRAM_BOT_TOKEN`
   - **Значение:** ваш токен из @BotFather (например, `123456789:AAE...`)
3. (Опционально) Добавьте переменную:
   - **Имя:** `DATA_DIR`
   - **Значение:** `/data`

### Шаг 4. Настройка постоянного хранилища (Persistence)
1. В настройках проекта Amvera перейдите во вкладку **«Хранилище»** (Storage).
2. Убедитесь, что смонтирована папка постоянного хранилища с точкой монтирования:
   - **Путь в контейнере:** `/data`
   *(Это гарантирует сохранение всех записей журнала, опросов и студентов при любых пересборках проекта!)*

### Шаг 5. Сборка и Запуск
1. Нажмите кнопку **«Собрать и развернуть»** (или просто сделайте push в ветку `main` GitHub — Amvera автоматически подхватит изменения).
2. Откройте вкладку **«Логи»** и убедитесь в успешном старте:
   ```
   🤖 Бот «Староста 24» запущен: @ваш_бот
      Режим: Long Polling (без вебхука)
      База данных: /data/db.json
      Amvera persistent /data: ДА (данные защищены при деплоях)
   ```
3. Откройте Telegram и напишите боту команду `/start`!

## 💻 Локальный запуск для разработки

Если вы хотите протестировать бота на компьютере:

```bash
# 1. Скопируйте файл примера переменных
cp .env.example .env

# 2. Вставьте ваш токен в .env:
# TELEGRAM_BOT_TOKEN="123456789:AAE..."

# 3. Запустите проверку синтаксиса
npm run check

# 4. Запустите бота
npm start
```
